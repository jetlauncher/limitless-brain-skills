## Notes

| File | เรื่องอะไร |
|---|---|
| `00 Start here.md` | หน้าแรกของสมองบริษัท ภาพรวมทั้งบริษัท |

## Rules

- โฟลเดอร์นี้มีโน้ตเดียว คือ `00 Start here.md` ไม่สร้างโน้ตอื่นที่นี่
- ข้อมูลภาพรวมเปลี่ยน ให้แก้ในโน้ตเดิม เฉพาะส่วนที่เปลี่ยน
- รายละเอียดยาวเก็บในโฟลเดอร์ของเรื่องนั้น (`SOP/`, `FAQ/`, `Products & prices/`) แล้วใส่ลิงก์จากหน้านี้
- **ดูแลสารบัญนี้ให้ตรงเสมอ**: เพิ่ม เปลี่ยนชื่อ หรือลบโน้ตในโฟลเดอร์นี้ ให้แก้ตารางข้างบนด้วย
