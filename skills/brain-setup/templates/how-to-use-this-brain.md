# How to use this brain

กฎที่ AI ทุกตัว (Claude, ChatGPT, Codex, Cursor) ต้องทำตามเมื่อใช้สมองบริษัทนี้
คนในทีมอ่านได้ เพื่อเข้าใจว่า AI ทำงานอย่างไร เจ้าของเป็นคนแก้กฎในโน้ตนี้

## ก่อนตอบทุกครั้ง
1. อ่าน [[00 Start here]] ก่อน
2. ค้นในสมองบริษัทก่อนตอบ (`search_notes`) แล้วเปิดอ่านโน้ตที่เกี่ยวข้อง (`read_note`) ห้ามตอบจากความจำ
3. บอกว่าคำตอบมาจากโน้ตไหน เช่น "ตาม SOP ขาย & ราคา: ..."

## ห้ามเดา
- ห้ามแต่งราคา ส่วนลด นโยบาย หรือคำสัญญากับลูกค้า ที่ไม่มีในโน้ต
- หาไม่เจอ ให้ตอบว่า "ยังไม่มีในสมองบริษัท" แล้วบอกว่าควรถามใคร (ดูหัวข้อ "ใครดูแลเรื่องอะไร" ใน [[00 Start here]])
- โน้ตสองอันบอกไม่ตรงกัน ห้ามเลือกเอง ให้บอกทั้งสองแบบพร้อมชื่อโน้ต แล้วให้เจ้าของตัดสิน
- คำตอบที่มีสถานะ "รอเจ้าของยืนยัน" หรือ "รอเจ้าของตอบ" ยังใช้ตอบลูกค้าเป็นคำตอบสุดท้ายไม่ได้
- โน้ตที่มีป้าย [ตัวอย่าง] เป็นข้อมูลสมมติ ห้ามใช้ตอบลูกค้า

## เก็บข้อมูลใหม่ให้ถูกที่
| ข้อมูลใหม่ | เก็บที่โฟลเดอร์ | ตั้งชื่อโน้ต |
|---|---|---|
| ภาพรวมบริษัท | `00 Start here` | มีโน้ตเดียว คือ `00 Start here` |
| ขั้นตอนการทำงาน | `SOP` | `SOP <เรื่อง>` |
| คำถามที่ลูกค้าหรือทีมถามบ่อย | `FAQ` | `FAQ <หมวด>` เช่น `FAQ ราคา & ส่วนลด` (หนึ่งหมวด หลายคำถาม) |
| สินค้า แพ็กเกจ ราคา | `Products & prices` | ชื่อสินค้าหรือหมวดสินค้า |
| ข้อมูลลูกค้า | `Customers` | ชื่อลูกค้าหรือชื่อบริษัทลูกค้า |
| บันทึกประชุม | `Meetings` | `YYYY-MM-DD <หัวข้อ>` |
| การตัดสินใจ | `Decisions` | `YYYY-MM-DD <เรื่อง>` |
| คนในทีม และงานของแต่ละคน | `Team` | ชื่อเล่น |
| กฎและรายการงานของ AI | `_AI` | |

## วิธีเขียน
- ค้นก่อนเขียนทุกครั้ง มีโน้ตเรื่องนั้นแล้วให้แก้โน้ตเดิม ห้ามสร้างโน้ตซ้ำ
- แก้เฉพาะส่วนที่เปลี่ยน (`edit_note` พร้อม `expectedRevision`) ห้ามเขียนทับทั้งโน้ต
- ทุกการตัดสินใจต้องมีวันที่แบบ `YYYY-MM-DD` (ปี ค.ศ. เวลาไทย) และบอกว่าใครตัดสิน
- ข้อมูลเปลี่ยน ให้เขียนว่า "(เปลี่ยนเมื่อ YYYY-MM-DD จากเดิม: ...)" ห้ามลบของเดิมทิ้งเงียบๆ
- ราคาและนโยบายเปลี่ยนได้เมื่อเจ้าของ หรือคนที่เจ้าของมอบหมาย สั่งเท่านั้น
- เขียนภาษาไทยง่ายๆ ประโยคสั้น
- ใส่ลิงก์ไปยังโน้ตที่เกี่ยวข้องด้วย `[[ชื่อโน้ต]]`

## ห้ามเก็บ
รหัสผ่าน เลขบัตรประชาชน เลขบัญชีธนาคาร เลขบัตรเครดิต และข้อมูลส่วนตัวของลูกค้ารายบุคคล (เบอร์โทร ที่อยู่ LINE ID) ห้ามใส่ในโน้ตใดๆ

## โฟลเดอร์ `_AI`
โน้ตใน `_AI` เป็นกฎและรายการงาน ไม่ใช่ข้อเท็จจริงของบริษัท ห้ามใช้ตอบลูกค้า
`_AI/Weekly review` คือรายการที่เจ้าของตรวจทุกวันศุกร์ ในนั้นอาจมีราคาที่ขัดกันอยู่โดยตั้งใจ ห้ามใช้เป็นที่มาของคำตอบ

## Team skills ที่ใช้คู่กัน
- brain-setup: สร้างสมองชุดเริ่มต้น
- brain-writeback: จบงานแล้วบันทึกสิ่งใหม่กลับลงสมอง
- meeting-to-brain: บันทึกประชุมลงสมอง
- faq-from-chats: อัปเดต FAQ จากแชท LINE OA
- weekly-brain-review: รีวิวสมองทุกวันศุกร์
